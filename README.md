# Epsilon-6 ATB

Минимальный Discord-бот на Python, который присутствует на сервере и показывает
статус:

> Я существую

Проект начинается с чистой и простой основы. Команды, дополнительные модули,
модерация и верификация будут добавляться постепенно.

## Возможности

- подключается к Discord;
- отображается как `Epsilon-6 ATB`;
- устанавливает пользовательский статус `Я существую`;
- использует минимальные Discord intents;
- не обрабатывает сообщения и команды на текущем этапе.

## Требования

- Python 3.13 или новее;
- Discord-приложение с созданным ботом;
- токен Discord-бота.

## Запуск в Replit

1. Создайте секрет `DISCORD_TOKEN` в Replit Secrets.
2. Добавьте Discord-бота на нужный сервер.
3. Запустите workflow **Discord Bot**.

Проект запускается командой:

```bash
python main.py
```

Если токен не настроен, приложение завершится с понятным сообщением об
ошибке. Сам токен не хранится в исходном коде и не должен добавляться в Git.

## Локальный запуск

Установите зависимости проекта, затем задайте переменную окружения:

```bash
export DISCORD_TOKEN="ваш_токен_бота"
python main.py
```

В Windows PowerShell:

```powershell
$env:DISCORD_TOKEN = "ваш_токен_бота"
python main.py
```
